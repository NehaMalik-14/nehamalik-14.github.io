Taking AI from proof of concept to everyday tooling

At Accenture I led a proof of concept that put large language models to work across the whole automation lifecycle, so entry-level engineers could create and run scripts without deep programming knowledge. Teams across multiple projects went on to adopt it.

  1. Start from the requirement

    User stories and requirements are the starting point for test design.

  2. Generate test cases with an LLM

    The model drafts test cases, including edge cases that are easy to miss by hand.

  3. Execute them as automation

    Generated cases run as automated scripts, so less experienced engineers can contribute without deep coding.

  4. Run in the pipeline

    Automated suites run in Jenkins and Azure DevOps CI/CD pipelines, versioned in Git.

  5. Report and improve

    QA dashboards track coverage, defects and release readiness.
